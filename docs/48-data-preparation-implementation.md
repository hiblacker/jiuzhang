## 页面与数据边界

- 数据源仅配置入口，不承载清洗、业务聚合或数据集刷新规则。
- 数据集管理输入、处理步骤、输出粒度/唯一键、预览、质量、刷新、版本与血缘。
- 保存草稿不改变当前服务版本；发布必须基于通过质量检查的新结果。
- 每次运行固定上游版本及原始批次，保存来源、事件时间、入库时间和批次追溯；时间窗口为半开区间。
- 空值、删除、去重保留策略必须显式声明；不替业务推断历史或聚合口径。
- “服务数据集”菜单更名“数据服务”；旧 `/systems` 跳转 `/preparation/sources`；业务系统入口保留于 `/settings/systems`。

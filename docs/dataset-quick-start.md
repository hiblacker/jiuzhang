# 数据集快速操作

新建／编辑页直接配置名称、提供方式及入库设置，选择数据源、定义取数后保存草稿；不配置清洗或脱敏，也没有步骤导航和保存表单弹窗。保存后进入详情页，再配置字段、清洗、质量规则与脱敏策略。

## 新建并保存

标题栏默认显示「新建数据集」，点击名称或右侧编辑图标原位改名；Enter 确认、Esc 撤销本次修改，合法名称失焦自动确认。名称先写入本地草稿，点击「保存草稿」才持久化；未命名保存会自动聚焦标题栏并提示必填。长名称省略显示，悬停可查看完整名称。

左侧固定 280px，默认「取数」页签；切到「设置」选择提供方式、目标层、目标表和「全量替换／追加写入」，默认全量替换。负责人、标签、说明、主题域和 SQL 模式的可选业务主键在「更多信息」中就地展开，收起不会清空。选择直连时隐藏入库设置。设置区域超出高度时只滚动左侧；切换页签不清空 SQL、预览、光标、结果分隔位置或目录状态。右侧工作区从 64px 标题栏下方开始，占满剩余宽高。

在标题栏选择定义方式和数据源。数据源支持搜索，列表默认请求前 20 个匹配项。选好数据源后，在左侧按名称搜索表或工作表。

- **选择数据表**：在左侧选择数据表。入库数据集可在下方「表字段与业务主键」选一个或多个输出字段作为业务主键。右侧点击「读取数据」查看原始取数结果。
- **自定义 SQL**：点击左侧目录中的表，下方「表字段参考」会显示该表的字段，可将表名或字段插入编辑器；右侧编写所选数据库方言的只读 SQL，点击「运行 SQL」或按 `Ctrl/⌘ + Enter`，结果显示在编辑器下方。`Ctrl + Space` 打开表和字段补全；可拖动结果分隔条调整区域高度。
- 点击页头「保存草稿」直接校验并保存，不再弹出填写表单。名称错误在字段下显示并聚焦；请求失败保留输入。若当前定义尚未成功确认，保存会先运行查询并读取字段结构。运行 SQL 只做预览；保存不会发布或入库。

SQL 查询在所选 MySQL / OceanBase MySQL / PostgreSQL 源库执行，支持 CTE、JOIN、子查询、聚合和窗口函数。MySQL/OceanBase 的未限定表名按目录匹配大小写，如 `select * from story`；重名时须使用实际表名以消除歧义。PostgreSQL 遵循原生规则：未加引号名称折为小写，双引号保留大小写，平台不会自动改写。只允许一条只读查询。预览最多 100 行、30 秒及 10 MiB；不允许 DDL、DML、多语句、文件写出及已知副作用函数。敏感数据预览仍要求服务端 `readSensitive` 权限。

## 在详情页配置处理

Excel 的接入步骤见下方「Excel 数据源」；保存后的处理配置与 MySQL / OceanBase / PostgreSQL 共用此流程。

打开数据集详情的「清洗与脱敏」页签，点击「配置清洗与脱敏」后调整字段映射、字段级/统一脱敏策略、质量规则和 trim。点击「预览处理结果」检查结果，再保存处理配置。修改草稿后重新发布，已发布版本保持不变。

质量规则在正式直连查询或完整入库运行时检查，样本预览不等于正式质量验收。选表模式需要等值过滤或字段节点时，可展开「可视化加工」；复杂关联、聚合或计算使用定义页的 SQL。

修改 SQL 或数据源后重新读取取数结构。仍存在的源字段会保留已有映射，新字段追加，已移除字段会提示复核。字段/规则/画布变更会使处理预览失效；取数结果与处理结果分开显示。

## 提供方式与发布

- **直连数据源**：发布后由平台查询接口读取数据源，不创建仓库快照或运行任务；MySQL / OceanBase / PostgreSQL 实时读取源库，Excel 读取发布时绑定的文件。
- **入库到数仓**：配置目标层、目标表和写入方式，业务主键为可选元数据，不参与全量／追加去重；发布后可手动运行或按 Cron／固定间隔运行，将结果写入 Doris，并按已发布版本的写入方式更新该数据集独占目标表。在详情的「调度」页签点击「配置调度」，可原位修改并保存调度方式、时区和超时。任务中心也可编辑同一份配置。

入库有两种写入方式：

- **全量替换**：每次成功运行，用本次结果替换全部已有数据。
- **追加写入**：保留已有数据，追加本次结果；不按业务键去重，相同记录再次被 SQL 查到也会再次写入。定时策略只控制执行时间，SQL 决定本次查询范围；平台不推导日期窗口、不回算历史、不同步更新或删除。

追加零行正常成功并保留已有数据，不需要「允许空结果覆盖」。同一次运行的恢复／同一个幂等请求不重复追加；用户新建一次运行则是新批次。输出列名、类型或可空性与当前数据不兼容时阻断，已有数据不变。

编辑已发布数据集会同时标明当前生效方式及待发布修改。写入方式允许修改，保存只更新草稿，重新发布后对新建运行生效；已创建运行和重试仍绑定原版本。从追加切回全量时，就地提示覆盖影响，并在现有发布确认中再次说明；发布本身不会修改数据。任务页只读展示已发布方式，修改入口指向数据集；运行历史显示本次实际方式和行数。

新建默认入库。草稿可先不填写目标表，但发布入库版本前必须填写。首次发布后，提供方式和入库目标表固定。计划配置保存在 PostgreSQL，Worker 使用持久化的下一次触发时间投递运行；暂停会阻止后续新运行。当前自动重试、任务依赖和补数未开放。保存草稿不会发布或写入数仓。

## OceanBase 数据源（MySQL 模式）

在新建数据源中选择「OceanBase (MySQL)」，默认端口 2881、默认启用 TLS。账号须完整填写：直连 observer 使用 `user@tenant`，经 ODP 使用 `user@tenant#cluster`；平台不会改写账号。编辑密码留空保留原凭证，改账号须同时提供密码。测试连接后保存，可复用选表/SQL、处理、发布、直连或入库流程。

选表全量入库要求显式主键，包含复合主键也可，主键可以不输出；按主键游标分批，不用 OFFSET。无显式主键时可用自定义只读 SQL，以单条查询游标读取。目录行数显示未知，不使用 OceanBase 返回为 0 的 TABLE_ROWS 作为实际行数。强一致会话与超时由服务端设置，失败或取消沿用既有运行语义。

本机回环无 TLS 实例可以关闭开关，认证不使用 MySQL 公钥文件；外部连接必须启用 TLS，服务端校验证书与主机名，CA 由部署者配置 JVM 信任库。本机 CE 4.4.2.1 observer 的发现/查询/扫描与 Doris 入库已验证；ODP、外部证书和客户环境仍待真实验证。不支持 Oracle 模式、增量或 CDC。

## PostgreSQL 数据源

新建数据源选择「PostgreSQL」，默认端口 5432、Schema 为 public、默认开启 TLS。一个数据源发现一个 database/schema 的表；多个 schema 可分别建立数据源。空 Schema 按 public 处理。账号凭据沿用服务端加密保存、编辑留空密码保留的流程。

选表读取显式限定 schema；自定义 SQL 按源账号权限执行，可写 `SELECT * FROM "Retail"."Orders"`。插入表名/字段与编辑器补全会保留双引号和大小写。表发现包含普通表及分区表；视图可通过自定义 SQL 读取。目录行数为未知，不用统计估值作为实际行数。

选表和 SQL 全量都在同一个只读、可重复读事务内使用每批 500 行前向游标，不要求主键，不使用 OFFSET，也不保存为下次运行的增量位点。预览、直连、处理、发布和 Doris 入库沿用既有流程。

首版支持整数、有限精度 numeric(p,s)、布尔、字符文本、date、timestamp/timestamptz；UUID、JSON/JSONB 作为字符串。整数和 Decimal 保持精确值。定点数须有精度/尺度，precision≤38 且 0≤scale≤precision；无约束 numeric、更大或特殊尺度、浮点、数组、bytea、范围等返回明确错误，可在 SQL 中显式转为支持的 numeric 或 text。timestamp 保留无时区值，timestamptz 转成 UTC datetime，入库不保留原时区标识；无限日期/时间戳不支持。

TLS 验证证书链和主机名，私有 CA 由服务端配置 `JIUZHANG_POSTGRESQL_SSL_ROOT_CERT`，不在浏览器上传凭据或证书。仅本机回环允许关闭 TLS。本地 17.6 已验证 TLS 成功、错误 CA、主机名不匹配及读取/入库；客户版本和证书链需按目标环境验证。

## Excel 数据源

1. 在「数据源 → 新建数据源」将类型切换为 Excel，上传 `.xls` 或 `.xlsx` 文件。文件保存在平台私有对象存储，不依赖本机 Excel 程序或共享目录。
2. 选择工作表，设置从 1 开始计数的表头行。一个数据源选择一张工作表；编辑时可以切换工作表或替换文件。表头须非空、忽略大小写后不重复，每列名称不超过 64 个字符。原始样本预览限管理员，最多 100 行及 10 MiB；developer 可以上传、校验和保存。
3. 校验文件并保存，从对象目录点击「从此对象新建数据集」，选择「读取数据」后保存。Excel 不支持源端 SQL，字段映射、清洗、质量和脱敏仍在数据集详情配置。中文表头会保留显示名称，并生成合法的默认输出名，可在详情页修改。
4. 数据集可选择直连读取或全量入库，也可配置现有手动/Cron/固定间隔任务。发布版本绑定当时的文件、工作表和表头行；替换源文件后，旧版本查询、运行和重试继续读取旧文件，重新发布的版本才使用新文件。

文件最大 20 MiB，解压后总大小最多 64 MiB；所选工作表最多 200 列、10 万行数据、100 万个单元格。空白行忽略，空单元格为 null，文本空字符串与文本前导零保留。数字从存储值精确读取，金额保留精度/小数位；Excel 已丢失的数值精度无法恢复，长编号应在原文件中存为文本。日期按 Excel 的日期系统读取为本地日期时间；混合类型列按字符串处理，可在数据集详情显式转换。

不执行公式、宏或外部工作簿引用；公式只读取已缓存结果，没有结果或包含错误单元格时明确拒绝，须在 Excel 中计算并保存后重新上传。加密、损坏或不支持的文件会返回明确错误，保留页面草稿供重试。

没有被数据源或发布版本引用的上传文件，满 24 小时后由 Worker 回收；存储删除失败保留持久重试记录。仍被历史版本引用的文件不会回收，历史运行的重试继续使用原文件。恢复操作恢复历史处理定义；再次发布时按当前数据源绑定文件，表结构变化时须先重新取数和调整字段。

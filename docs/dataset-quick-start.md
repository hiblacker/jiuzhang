# 数据集快速操作

新建数据集页只负责选择数据源、定义取数和保存基础信息，不配置清洗或脱敏，也没有步骤导航。保存后进入详情页，再配置字段、清洗、质量规则与脱敏策略。

## 新建并保存

左侧选择定义方式和数据源，可搜索数据源；列表默认请求前 20 个匹配项。选好数据源后，对象目录支持搜索表名。

- **选择数据表**：在左侧目录选择表，右侧点击「读取数据」查看原始取数结果。
- **自定义 SQL**：左侧选择表可查看字段并将表名/字段插入编辑器；右侧编写 MySQL 只读 SQL，点击「运行 SQL」或按 `Ctrl/⌘ + Enter`，结果显示在编辑器下方。`Ctrl + Space` 打开表和字段补全；可拖动结果分隔条调整区域高度。
- 点击页头「保存」，填写数据集名称等基础信息和提供方式，再保存草稿。若当前定义尚未成功确认，保存会先运行查询并读取字段结构。

SQL 查询在所选 MySQL 源库执行，支持 CTE、JOIN、子查询、聚合和窗口函数；SQL 关键字和未限定表名大小写不敏感，如 `select * from story`。表名按所选数据源目录匹配，区分大小写后重名时须使用目录中的实际表名以消除歧义。只允许一条只读查询。预览最多 100 行、30 秒及 10 MiB；不允许 DDL、DML、多语句、文件写出及已知副作用函数。敏感数据预览仍要求服务端 `readSensitive` 权限。

## 在详情页配置处理

Excel 的接入步骤见下方「Excel 数据源」；保存后的处理配置与 MySQL 共用此流程。

打开数据集详情，点击「配置清洗与脱敏」后调整字段映射、字段级/统一脱敏策略、质量规则和 trim。点击「预览处理结果」检查结果，再保存处理配置。修改草稿后重新发布，已发布版本保持不变。

质量规则在正式直连查询或完整入库运行时检查，样本预览不等于正式质量验收。选表模式需要等值过滤或字段节点时，可展开「可视化加工」；复杂关联、聚合或计算使用定义页的 SQL。

修改 SQL 或数据源后重新读取取数结构。仍存在的源字段会保留已有映射，新字段追加，已移除字段会提示复核。字段/规则/画布变更会使处理预览失效；取数结果与处理结果分开显示。

## 提供方式与发布

- **直连数据源**：发布后由平台查询接口读取数据源，不创建仓库快照或运行任务；MySQL 实时读取源库，Excel 读取发布时绑定的文件。
- **入库到数仓**：配置目标层、目标表和业务主键；发布后手动运行或在任务中心配置 Cron/固定间隔计划，将结果写入 Doris 并替换该数据集独占目标表的当前快照。打开「任务中心」找到该数据集任务，点「配置」设置 Cron/固定间隔、时区和超时；数据集详情的「调度」标签也有直达配置入口。

新建默认入库。草稿可先不填写目标表，但发布入库版本前必须填写。首次发布后，提供方式和入库目标表固定。计划配置保存在 PostgreSQL，Worker 使用持久化的下一次触发时间投递运行；暂停会阻止后续新运行。当前自动重试、任务依赖和补数未开放。保存草稿不会发布或写入数仓。

## Excel 数据源

1. 在「数据源 → 新建数据源」将类型切换为 Excel，上传 `.xls` 或 `.xlsx` 文件。文件保存在平台私有对象存储，不依赖本机 Excel 程序或共享目录。
2. 选择工作表，设置从 1 开始计数的表头行。一个数据源选择一张工作表；编辑时可以切换工作表或替换文件。表头须非空、忽略大小写后不重复，每列名称不超过 64 个字符。原始样本预览限管理员，最多 100 行及 10 MiB；developer 可以上传、校验和保存。
3. 校验文件并保存，从对象目录点击「从此对象新建数据集」，选择「读取数据」后保存。Excel 不支持源端 SQL，字段映射、清洗、质量和脱敏仍在数据集详情配置。中文表头会保留显示名称，并生成合法的默认输出名，可在详情页修改。
4. 数据集可选择直连读取或全量入库，也可配置现有手动/Cron/固定间隔任务。发布版本绑定当时的文件、工作表和表头行；替换源文件后，旧版本查询、运行和重试继续读取旧文件，重新发布的版本才使用新文件。

文件最大 20 MiB，解压后总大小最多 64 MiB；所选工作表最多 200 列、10 万行数据、100 万个单元格。空白行忽略，空单元格为 null，文本空字符串与文本前导零保留。数字从存储值精确读取，金额保留精度/小数位；Excel 已丢失的数值精度无法恢复，长编号应在原文件中存为文本。日期按 Excel 的日期系统读取为本地日期时间；混合类型列按字符串处理，可在数据集详情显式转换。

不执行公式、宏或外部工作簿引用；公式只读取已缓存结果，没有结果或包含错误单元格时明确拒绝，须在 Excel 中计算并保存后重新上传。加密、损坏或不支持的文件会返回明确错误，保留页面草稿供重试。

没有被数据源或发布版本引用的上传文件，满 24 小时后由 Worker 回收；存储删除失败保留持久重试记录。仍被历史版本引用的文件不会回收，历史运行的重试继续使用原文件。恢复操作恢复历史处理定义；再次发布时按当前数据源绑定文件，表结构变化时须先重新取数和调整字段。

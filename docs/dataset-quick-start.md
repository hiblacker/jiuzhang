# 数据集快速操作

新建和编辑数据集均使用全屏工作区，按 **定义取数 → 清洗与脱敏 → 输出与保存** 操作。顶部可以返回已满足条件的步骤，底部显示继续条件；退出时会确认是否放弃未保存修改。

## 1. 定义取数

先选 MySQL 数据源，再选择定义方式。此时无需填写数据集名称、负责人或目标表。

- **选择数据表**：在左侧搜索并选择表，点击「读取数据」，右侧显示该表的取数结果。
- **自定义 SQL**：左侧表名和字段仅供参考、支持复制，不会改写 SQL。在右侧编写 SQL 后点击「运行 SQL」，结果直接显示在下方；分隔条可拖动，也可聚焦后用上下方向键调高。

取数结果是清洗、字段映射与脱敏前的数据，仅有敏感数据读取权限的账号可以预览。运行成功后点击「确认取数，下一步」。空结果但有有效字段也能继续。

SQL 负责源端的关联、筛选、聚合及计算，支持 CTE、JOIN、子查询和窗口函数。仅允许一条只读查询，在所选源库内执行，不支持跨数据源关联。预览最多 100 行、30 秒及 10 MiB；不允许 DDL、DML、多语句、文件写出及已知副作用函数。

## 2. 清洗与脱敏

对上一步返回的结果字段进行配置：

1. 修改输出名、类型、字段顺序、说明和输出开关；小数可填写 `decimal(12,4)` 以明确精度。
2. 按需开启「去除首尾空白」，选择字段脱敏策略并标记敏感字段，或配置统一脱敏策略和质量规则。
3. 点击「预览处理结果」，在下方检查改名、类型转换、清洗与脱敏后的数据。成功后点击「确认处理，下一步」。

质量规则在正式直连查询或完整入库运行时检查，样本处理预览不等于正式质量验收。

选表模式需要等值过滤或字段节点时，展开「可视化加工」：选择节点类型并添加，选中节点后按提示配置，再通过起点、终点添加连线。不需要这些操作时保留默认读取节点即可；复杂计算使用第一步的 SQL。

修改字段、清洗或治理配置只会清空处理结果；取数结果继续保留。处理预览失败时保留草稿，按 message 提示调整后重新预览。

## 3. 输出与保存

填写数据集名称、负责人等信息，选择提供方式：

- **直连数据源**：发布后通过平台查询接口实时读取源库，返回字段处理与脱敏后的结果，不创建仓库快照或运行任务。
- **入库到数仓**：配置目标层、目标表、业务主键等，发布后手动运行，将处理结果写入 Doris，以完整快照替换该数据集独占目标表的当前数据。

新建默认入库。目标表可在保存草稿时留空，但入库发布前必须填写；首次发布后，提供方式和入库目标表固定。首版仅支持手动全量快照替换，未开放自动调度。

点击「保存草稿」回到详情，再单独「发布版本」。保存不触发发布或入库；发布后的直连数据集可查询，入库数据集还需手动运行。

## 返回修改 SQL 或源表

返回第一步修改 SQL 后，必须重新运行确认结构。仍存在的源字段会保留改名、类型、顺序、输出和脱敏配置；新字段追加，已移除字段显示提醒，请复核输出主键和规则。随后重新预览处理结果，再继续保存。

切换数据源、源表或定义方式会重新建立对应字段映射。取数和处理预览是两次独立的受限查询，不承诺读取同一时刻的源数据。每次查询仍遵守服务端读取与资源限制；直连正式查询最多 1000 行。

# 数据集快速操作

数据集有两个独立设置：**定义方式**决定从数据源怎样取数，**提供方式**决定查询时直连源库还是读取 Doris 中的入库快照。

## 选择数据表（可视化）

1. 打开「数据集 → 新建」，填写名称，选择 MySQL 数据源，并将「定义方式」设为「选择数据表」。
2. 选择一张源表。画布会从「读取源表」节点开始；当前可视化模式支持单张表、等值过滤和字段节点。
3. 需要过滤时，在画布上方选择「过滤」并点击「添加节点」，选中节点后按 `字段名=值` 填写条件，例如 `status=paid`。用「连线起点」「连线终点」和「添加连线」把节点接到读取节点后；可拖动节点调整位置。选中节点后可删除节点，连线列表可单独删除连线。不需要过滤时，保留默认读取节点即可。
4. 打开「字段与清洗」页，编辑输出字段名和字段类型，取消勾选不需要输出的字段，并按需设置说明和脱敏策略。小数精度可输入 `decimal(12,4)`。
5. 点击顶部「预览样本」检查转换结果，再保存。需要入库时，在「输出与入仓」填写目标表后发布，再手动运行；选择直连时，发布后即可查询。

JOIN、聚合、窗口函数等复杂查询请使用「自定义 SQL」模式；可视化画布当前不支持这些节点。

## 自定义 SQL

1. 选择数据源，将「定义方式」切换为「自定义 SQL」。
2. 输入一条 MySQL 只读 `SELECT`，点击「预览样本」。首次预览会执行 SQL 并读取返回字段。
3. 在「字段与清洗」页修改输出字段名、类型、输出开关和脱敏策略，再点「预览样本」查看最终结果。修改 SQL 后点击「重新读取 SQL 字段」，再检查字段映射。

SQL 支持 CTE、JOIN、子查询、聚合、窗口函数及常用计算表达式。只允许一条只读查询；预览最多 100 行、执行上限 30 秒和 10 MiB。拒绝 DDL、DML、多语句、文件写出和已知副作用函数。SQL 在所选数据源对应的数据库内执行，不支持跨数据源关联。

## 选择提供方式

- **直连数据源**：保存并发布后，平台服务端按请求实时查询源库，通过数据集查询接口返回脱敏结果；不会创建 Doris 快照或运行任务。查询受 1000 行和 10 MiB 上限约束。
- **入库到数仓**：保存并发布后，可手动运行数据集，将转换及脱敏结果写入 Doris，并以完整快照替换该数据集当前目标表数据。目标表必须独占，首版仅支持快照替换。

新建数据集默认选择「入库到数仓」。**预览和保存草稿不要求先填写目标表**，发布时校验；首次发布后，提供方式和入库目标表固定。选择直连时不需要配置目标表。可视化定义和 SQL 定义都能搭配这两种提供方式。

## 运行范围

首版调度为手动运行。直连数据集发布后通过数据集查询接口实时读取源库；入库数据集发布后通过「运行」写入最新完整快照。预览最多返回 100 行；直连查询最多 1000 行，均受服务端结果大小与超时上限约束。

# 九章前端页面与验收矩阵

> 2026-10-16 · 38 个路由入口均已映射实际页面，当前状态为 implementing。主流程已有浏览器证据，但完整交互与视觉验收尚未全部完成；不得仅按路由覆盖标记 verified。
> 主方案：[前端设计](frontend-design.md)；规则：[AI 开发规范](ai-development.md) · [UI 与 Vue 约定](ui-conventions.md)。

## 1. 统计口径

- 38 个路由入口；新增与编辑有独立 URL，但复用表单组件。
- 详情 tab、弹窗、抽屉和向导步骤不另算页面数量，仍必须完成对应交互。
- 根路径 / 重定向 /overview；未知路径 catch-all 重定向 /404，不额外计数。
- 所有 ID 都应支持从地址栏直接访问，刷新后恢复同一资源；路由参数必须校验。
- “所有页面”指本矩阵定义的三层数仓及配套管理范围，不包含 Crest 的仪表盘、大屏编辑器、AI 对话或任意报表搭建器。

## 3. 页面子视图要求

### 数据源创建/编辑

连接器选择 -> 基本信息 -> 参数与认证占位 -> 模拟测试 -> 保存。

数据库配置含主机/端口/库/schema、TLS 配置占位、读取策略；API 含 method/baseURL/path、headers/query/body、认证类型、分页、dataPath、增量字段、限流与错误语义。所有值为虚构，不能发请求到填写的真实 URL。连接器注册表声明表单字段与能力，不在一张大表单堆积所有类型的 if/else。

文件类使用示例 CSV/XLSX/JSON 的预设元数据和样本；首期支持虚构 CSV 的浏览器本地解析，其余格式展示明确演示结果，不宣称已实现完整解析引擎。

### 数据集工作区

- 基本信息：名称/目录/负责人/标签/说明。
- 输入：选择已存在 source/object 或已发布 dataset，展示来源及 schema。
- 建模：SQL 或可视化节点输入/过滤/字段/Join/Union/聚合；环检测；配置面板。
- 字段：源名、目标名、类型、是否输出、排序、说明、敏感标签。
- 清洗：空值、字符串、类型、过滤、去重的显式演示规则。
- 质量：必填/唯一/范围/枚举/新鲜度；PASS/WARN/BLOCK。
- 脱敏：展示掩码、删除、泛化的模拟效果；Token/HMAC 等如未实现算法只显示有标签的示例映射。
- 调度：手动、Cron、固定间隔、依赖、超时、重试。
- 输出：目标层/表/业务键/写入语义。
- 预览：固定样本数据与校验信息，不能把任意 SQL 直接 eval 或用正则冒充数据库。
- 发布：版本摘要与确认，返回 immutable datasetVersion；运行始终绑定版本。

首期可视化规则与 SQL 不承诺无损双向转换；切换到 SQL 模式后应提示图转换的支持边界。不要生成看似复杂却永远返回同一张假表的“执行器”。

### 任务与仓库

运行详情保留 runId、datasetVersion、触发来源、阶段、日志、质量、输入/输出和错误码。每个任务的取消、重试和补数具备合法状态检查；重复动作可解释。仓库表详情与运行输出能互相导航。

### 通用页面状态

列表：loading、empty、success、error、forbidden；详情：同上并含 resource-not-found；表单：clean、dirty、invalid、submitting、failed、saved；运行：queued、running、validating、publishing、succeeded、failed、blocked、canceled。转移由 jobs 领域定义并与 [总体状态约定](architecture.md#61-运行与尝试) 一致：重试新建关联 runId，publishing 后取消冲突，BLOCK 不推进成功游标。调度任务的暂停/启用与运行终态分开。

## 6. 每页完成定义

1. 路由/菜单/面包屑正确，深链接及刷新可用。
2. 全部数据走 HTTP client，禁止页面导入 fixture；列表和统计有相同数据来源。
3. 主操作真实改变 Mock 状态；禁用/失败有原因；不得点击后只 toast 而无状态变化。
4. 保存/取消/刷新/删除/引用影响可重复验证。
5. 主要状态覆盖，视觉和键盘交互检查通过；无严重 console 错误。
6. 路由 lazy load，离开清理定时器/订阅/编辑器实例。
7. 契约、Mock、页面、相关测试一致，更新实施状态记录。
8. 明确哪些功能是演示，不能把前端验证当成后端安全或数据计算结果。
9. 涉及确认/复制/列表/编辑时复用已有行为；失败保留输入、重复点击不重复写、错误不双提示、焦点恢复可用。
10. 分享 URL、浏览器前进后退、过滤后页码/选择范围一致；文案 key 有对应 zh-CN，主题/可访问性遵循 UI 规范。

## 7. 状态维护方式

B0 建立与本矩阵 ID 对应的 route-manifest 和测试清单。运行时以一个路由元信息所有者生成菜单与导航；测试核对其与验收 ID 一致，避免复制三份独立 routes 常量。

实施状态使用 planned / implementing / verified。只有浏览器行为和必要自动检查通过才标记 verified，不以文件数量、截图数量或能显示标题判定完成。

## 迁移与恢复

新增 V018 账号/邀请表、V019 系统目录及项目关联；V001–V017 不变。现有 source、批次、模型、发布及原件身份保持。迁移由管理员显式执行，应用启动不自动修改 Schema。

浏览器身份与既有服务令牌分开；开户邀请只回显一次，24 小时内有效，数据库存摘要。负责人只能邀请新账号或管理本项目成员；已有账号密码重置由平台管理员执行。会话撤销/密码重置递增凭证版本，下次请求立即拒绝旧会话。重置后旧密码不能继续登录。

前端开发用 `npm run dev --prefix apps/console`，API 代理默认指向本机 60185；打包前运行前端构建，Maven 将 dist 纳入同源静态资源。一期页面保留为 [legacy.html](../apps/console/legacy.html)。整栈安装/切换脚本在 F 完成前仍属待升级，不声明当前运行服务已切换。

回退应用时保留新增表与迁移账本；不执行 DROP、不复用编码、不删原件。确认备份后向前修复配置及关联，再重启对应版本。未进行人工同行评审或生产部署。

# 06 测试、验收与运维

## 1. 测试层次

单元测试覆盖日期边界、增量游标、聚合规则和权限解析；集成测试覆盖数据库/接口/编排器；数据黄金样本验证口径；端到端测试验证源到报表；非功能测试验证容量、隔离、故障和恢复。

## 2. 必测场景与预期

| ID | 输入/动作 | 必须满足的结果 |
|---|---|---|
| T01 | 多页记录具有相同更新时间 | 无漏记录；重复回读不增加明细对象数 |
| T02 | 批次写入后、检查点提交前宕机 | 重试可重复读取，但目标无重复；审计可解释 |
| T03 | 源数据补录发生在已处理日期 | 受影响日/月和依赖重算，发布新版本 |
| T04 | 对象完成→重开→再次完成 | 完成事件2次；对象去重依口径；中间快照正确 |
| T05 | 团队月中变更 | 事件按已确认历史归属，不把全部历史改成当前团队 |
| T06 | 月末23:59:59.999和次月00:00事件 | 半开边界下两条归入正确月份 |
| T07 | 甲日1个有效样本周期10h，乙日9个各20h | 月均19h，不是15h；缺失时长不入分母 |
| T08 | 甲日1/1成功，乙日0/9成功 | 月成功率10%，不是50% |
| T09 | 同一人员连续两天活跃 | 月去重人数1，不是2 |
| T10 | 月末快照缺失但29日存在 | 月末值不冒充29日值；标记不完整并阻断/待补算 |
| T11 | 聚合分母为0 | 返回NULL和语义说明，不伪造0%/100% |
| T12 | 一个需求关联多个缺陷与任务 | 汇总前控制粒度，不发生需求计数乘法膨胀 |
| T13 | 只持有当前态、要求接入前历史 | 明确不支持准确恢复，不伪造状态历史 |
| T14 | 某来源物理删除但无删除流 | 触发约定对账方案或声明已知限制，不静默假装完成 |
| T15 | 数据集新版本一张表失败 | 当前发布不变；报表看不到半更新结果 |
| T16 | 较旧批次比新批次晚完成 | 发布版本比较拒绝旧覆盖 |
| T17 | 重试同一天/同月份三次 | 业务结果相同；运行attempt可区分 |
| T18 | 越权用户访问汇总、下钻、导出、缓存 | 全链路按同一政策拒绝或过滤 |
| T19 | 源字段改类型/删除 | 模式变化告警，阻断受影响模型，原始留存可追溯 |
| T20 | 从备份恢复元数据与业务发布对象 | 指针指向存在且匹配的数据版本；恢复过程有证据 |
| T21 | 新增销售合成主题 | 不修改核心代码完成接入、日月统计和数据集发布 |
| T22 | 流程回调重复/引擎短时失联 | 状态更新幂等；定期对账恢复实际状态 |

## 3. 对账和业务签字

统计范围包含时间水位、来源对象、状态、删除、排除、历史归属、口径版本。对账报告应同时列来源候选、有效入仓、隔离/排除、汇总结果和差异说明。

关键指标在人工核算小样本、合成边界样本和真实范围抽样上分别验证；业务负责人签字。未解决的关键差异不能靠“发布但备注”自动豁免。

## 4. 非功能验收（初始建议，M0冻结）

- 日报：用户授权实施方确定为T+1 06:00（Asia/Shanghai）前发布；真实源接入前核查上游可用时点，失败保留旧发布并标记延迟，不承诺未经实测的准点能力。
- 查询：用户明确历史总量百万级、每天新增几千条，300 QPS指报表数据库查询并允许按实测调整。优先测试SQL直连，不对DevOps源库压测；SQL组合、持续时长及最终吞吐门槛待确认，P95≤3秒仍为候选；分别报告成功吞吐和延迟，不以300连接替代300 QPS。详见[PoC输入与容量定义](11-poc-confirmed-inputs.md)。
- 容量：记录正常日、峰值日和整月重算的处理耗时、资源峰值和源负载；不得只测空库。
- 恢复：元数据/服务数据RPO和RTO由业务确认并实测；没有目标前不上线宣称高可用。
- 安全：未授权数据返回为零；凭证不得出现在API响应、日志、版本库和样例。
- 稳定性：连续10个工作日试运行，且完成历史月结回放、重试补数和恢复演练。

## 5. 运行手册最小闭环

1. 日报未更新：检查来源水位→接入批次→DAG→质量→发布；前端显示旧数据截止时间。
2. 接入失败：确认凭证/网络/限流；不手工跳过检查点；修复后从已提交批次恢复。
3. 指标错误：冻结受影响发布→定位模型/规则/来源→修复并测试→重算依赖区间→审批发布。
4. 质量失败：责任人确认异常/排除，关键失败阻断发布；任何豁免带原因、审批人和失效时间。
5. 历史补数：提交时间范围/主题/版本→估算影响和资源→审批→隔离计算→对账→切换。
6. 回滚：优先切回可用发布版本；数据库迁移按兼容策略修复，不盲目执行破坏性降级。
7. 备份恢复：恢复配置和元数据→恢复发布对象→检查manifest→验证授权和查询→恢复调度。
